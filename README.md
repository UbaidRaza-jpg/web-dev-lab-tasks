# Student Portal Basics & DOM Manipulation

This repository contains a collection of beginner-friendly web development assignments. The tasks focus on strict, vanilla frontend web development without the use of external libraries or frameworks like Bootstrap.

## Technologies Used
* **HTML5:** For semantic structure and form elements.
* **CSS3:** For basic styling, coloring, and brute-force layouts (no grid/flexbox shortcuts).
* **Vanilla JavaScript:** For interactive DOM manipulation and reading input values.

## Project Files

### 1. `index.html` (Student Dashboard)
A static, responsive-style dashboard layout created purely with HTML and CSS. It features a sidebar navigation menu, a banner, and organized cards for student finance and enrolled courses. 

### 2. `counter.html` (Interactive Counter)
A simple, barebones interactive counter. It demonstrates basic JavaScript variable assignment and event handling (`onclick`) to increment, decrement, and reset a number displayed on the screen using `.innerHTML`.

### 3. `profile.html` (Student Profile Generator)
An interactive webpage where a user enters a name and department. JavaScript reads the input values using `.value` and dynamically displays the information inside a styled profile card without reloading the page.

### 4. `registration.html` (Registration Preview Form)
A comprehensive HTML5 form that includes text, email, number, select dropdowns, and radio buttons. 
**Features include:**
* Reads all input values on submission.
* Validates that the Name and ID fields are not empty (displays an error if they are).
* Dynamically displays the entered data in a formatted preview card.
* Dynamically alters the CSS background color of the preview card using JavaScript.
* Includes a 'Clear Form' function to reset all inputs and hide the preview.

## How to Run
Since these are static files, no local server or installation is required. 
Simply clone the repository and double-click any of the `.html` files to open them directly in your web browser.
